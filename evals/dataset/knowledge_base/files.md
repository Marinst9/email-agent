# Подготовка на датотеки за печат

- Формат: PDF, 300 dpi, CMYK, со 3 mm bleed на секоја страна.
- Фонтовите треба да се конвертирани во криви (outlines).
- Датотеки до 50 MB се праќаат по мејл; поголеми преку WeTransfer линк.
- Пред печатење праќаме пробен отпечаток (PDF) на одобрување. Печатиме дури по писмено одобрување.
